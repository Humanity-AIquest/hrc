# Roadmap

Design documents for the constitutional operating system. These are rendered on
[humanity-ai.quest](https://humanity-ai.quest) directly from this directory, so
the site and the source never disagree — and so a contributor can amend the
roadmap by pull request like anything else.

| Document | Status |
|---|---|
| [`01-mcp-protocol.md`](01-mcp-protocol.md) | Designed, not built |
| [`02-firewall.md`](02-firewall.md) | Designed, schema written, not wired |
| [`03-phase-2-development.md`](03-phase-2-development.md) | Deferred until post-funding |

## Phases

**Phase 1 — ratify HRC v1.** Invite-only founding cohort, deliberation, voting,
and the protocol that lets members bring their own agent. No software delivery.

**Phase 2 — build the OS.** Open-source development under constitutional CI, with
agent contribution provenanced rather than banned. Post-funding.

The split is deliberate. A constitution ratified by a real community is a
stronger foundation — and a stronger thing to raise against — than a half-built
platform with no one in it.
